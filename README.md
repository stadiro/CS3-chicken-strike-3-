# WOW Arena

Сетевой браузерный 1v1-шутер в духе классических карт Counter-Strike: серверная физика, лаг-компенсация, кастомные прицелы и реконнект. Два режима: соревновательный MR12 с бомбой C4 и закупкой на `de_dust2` / `fy_wow`, и арена до 16 фрагов на `fy_sand`.

Стек: TypeScript, Node.js, Express, Socket.IO, Three.js, Vite.

## Возможности

- Авторитарный сервер: движение, коллизии, hitscan, урон, смерть, респавн, подбор оружия и счёт считаются только на сервере.
- Три карты: `fy_sand` — пересобранная по BSP песчаная арена 44 × 33.2 с двумя двухэтажными зданиями, гаражами, лестницами и укрытиями (режим `arena`); `fy_wow` (40 × 40, открытый центр) и `de_dust2` (68 × 68, классическая топология CS2: T-Spawn, Suicide, Mid с дверями и Xbox на Catwalk/Short A, Long House с двойными дверями, Pit, КТ-андерпас, двухуровневые Upper/Lower B-тоннели, B-Window, пленты A и B) — режим `buy` с бомбой C4, закупкой, экономикой и MR12. Карта переключается из веб-админки.
- Оружие: нож, Glock, USP-S, P250, Five-SeveN, Tec-9, Desert Eagle, Dual Berettas, MP9, MAC-10, MP5-SD, P90, AK-47, M4A1, Galil AR, FAMAS, SG 553, AUG, SSG 08, AWP, M249 и пять гранат (flash, smoke, HE, molotov/incendiary). В `arena` Alpha стартует с Glock, bravo — с USP, оружие со спавнов подбирается автоматически; `E` подбирает или заменяет оружие, `G` выбрасывает активное, кроме ножа. В `buy` режиме оружие покупается в меню закупки.
- Стрельба в стиле CS 1.6/CS2: у каждого оружия свой `armorRatio` и падение урона с дистанцией; пистолеты стреляют только по новому нажатию ЛКМ, автоматическое оружие — при удержании. Первые два выстрела при неподвижной стрельбе летят точно по перекрестию, затем включается спрей-паттерн. M249 стреляет со скоростью 750 выстрелов в минуту.
- Броня: в `arena` игрок начинает с нулевой бронёй, на `fy_sand` лежат два бронежилета по 100; в `buy` режиме кевлар, шлем и дефьюз-кит покупаются. Шлем защищает голову, без шлема хедшот проходит мимо брони. Подобранное оружие и броня не появляются заново до следующего раунда.
- Урон по зонам: голова ×4, ноги ×0.7; броня поглощает часть урона по правилам CS 1.6. Падение с высоты наносит урон без защиты бронёй. Ваншот в голову с шлемом проходит только у достаточно мощного оружия, как в CS2.
- Оптика: ПКМ включает и выключает прицел AWP и SSG 08; в прицеле чувствительность мыши снижена. Без оптики пользовательский прицел скрыт, разброс увеличен. После выстрела прицел скрывается и возвращается после цикла перезарядки, если игрок не выключил его повторно.
- Гранаты: в `arena` HE подбирается со спавна; в `buy` режиме покупаются flash, smoke, HE и molotov/incendiary. Всего максимум 4 гранаты, flash — до 2. Клавиша `4` циклически переключает тип, ЛКМ бросает с учётом скорости игрока. Гранаты нельзя выбрасывать вручную, но после смерти они выпадают вместе с оружием. HE наносит урон по радиусу; flash ослепляет с учётом дистанции, угла взгляда и перекрытия стен; smoke создаёт облако и тушит molotov/incendiary; огонь не возникает внутри активного дыма.
- Прыжок имеет буфер ввода, а низкие барьеры перешагиваются автоматически без прыжка. `Shift` переводит в тихий шаг: скорость снижается, шаги не слышны.
- Матч: в `arena` — до 16 фрагов или лучший счёт за 10 минут, убийство завершает раунд, победитель сохраняет оружие и броню. В `buy` — MR12: first to 13, смена сторон после 12 раундов, 12–12 = ничья, freeze 3 секунды, раунд 1:25, закупка 20 секунд live после freeze. Выживший сохраняет оружие, патроны, броню, шлем, кит и гранаты; в халфтайме деньги и лоадаут сбрасываются. В конце — экран результатов и рематч. После убийства выпавшее оружие и гранаты можно подобрать и перезарядиться даже в `round_over`.
- Сетевая модель: 30 Гц сервер, ввод до 120 Гц, серверная очередь действий (переключение оружия, перезарядка, подбор/выброс, граната) на случай, если между кадрами пришло несколько нажатий; интерполяция снапшотов с адаптивным буфером 70–180 мс, лаг-компенсация 300 мс.
- Реконнект: сессия хранится в `sessionStorage`, при потере связи матч встаёт на паузу до 60 секунд.
- Две вкладки на одной машине — это два разных игрока: у каждой вкладки своя сессия.
- HUD: здоровье, броня, деньги, патроны, слоты, таймер, счёт, killfeed, настраиваемый прицел, индикатор гранат, направление урона, ping/jitter/loss, плашка раунда, результаты и CS2-подобная таблица по `Tab`. В `buy` режиме — полноэкранное меню закупки с категориями, возвратом последней покупки и таймером, T/CT-подписи сторон и отметка «ВАША КОМАНДА».
- Настройки: чувствительность, отдельная чувствительность AWP, FOV, громкость master/effects, toggle-режимы ходьбы и прицела. Сохраняются в `localStorage` (`wow-settings-v1`) и доступны со стартового экрана и из паузы.
- Звук: выстрелы, попадания, хедшоты, шаги с панорамированием, whiz пуль рядом с игроком, перезарядка и смена оружия.
- Статистика: `round_summary` обновляет таблицу по `Tab` в конце каждого раунда; в ней показываются убийства, смерти, суммарный урон, HS% и accuracy за матч. Отдельного per-round overlay и killcam нет. Финальный раунд проходит окно `round_over`, после которого показывается экран результатов.
- Веб-админка: отдельный порт, живое состояние матча, смена карты вместе с режимом, кик, restart/end, объявления и остановка сервера; опциональная защита токеном.

## Быстрый старт

Требуется Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для игры вдвоём откройте вторую вкладку и введите второй позывной.

`npm run dev` поднимает один процесс: Express + Socket.IO + Vite middleware и отдельный HTTP-сервер админки. Отдельный dev-сервер Vite не нужен.

Админка доступна на `http://localhost:3001`. Порт и адрес можно изменить через `ADMIN_PORT` и `ADMIN_HOST`; по умолчанию сервер слушает только localhost. Для доступа с другого компьютера задайте `ADMIN_HOST=0.0.0.0` и обязательно `ADMIN_TOKEN`.

## Production

```bash
npm run build
npm start
```

`npm run build` проверяет типы, собирает клиент в `dist/client` и сервер в `dist/server`. `npm start` запускает собранный сервер и раздаёт статический клиент из `dist/client`.

Переменные окружения:

| Переменная    | По умолчанию | Назначение                                     |
| ------------- | ------------ | ---------------------------------------------- |
| `PORT`        | `3000`       | HTTP/Socket.IO порт                            |
| `HOST`        | `0.0.0.0`    | адрес прослушивания игрового сервера           |
| `ADMIN_PORT`  | `3001`       | порт веб-админки (должен отличаться от `PORT`) |
| `ADMIN_HOST`  | `127.0.0.1`  | адрес админки; localhost по умолчанию          |
| `ADMIN_TOKEN` | —            | токен доступа к API; минимум 8 символов        |
| `LOG_LEVEL`   | `info`       | `debug`, `info`, `warn`, `error`               |

Пример для PowerShell:

```powershell
$env:PORT = "8080"
npm start
```

`.env.example` содержит шаблон переменных. Автозагрузка `.env` не включена: задайте переменные через окружение или используйте `node --env-file`.

## Управление

| Клавиша               | Действие                                            |
| --------------------- | --------------------------------------------------- |
| `WASD`                | движение                                            |
| `ЛКМ`                 | огонь                                               |
| `ПКМ`                 | прицел AWP / SSG 08                                 |
| `Space`               | прыжок                                              |
| `Shift`               | тихий шаг                                           |
| `Ctrl` / `C`          | присесть                                            |
| `R`                   | перезарядка                                         |
| `B`                   | открыть/закрыть меню закупки                        |
| `E`                   | подобрать оружие / удерживать для Plant и Defuse C4 |
| `G`                   | выбросить оружие (`arena`) или бомбу C4 (`buy`)     |
| `1` / `2` / `3` / `4` | первичное / пистолет / нож / граната                |
| `Tab`                 | таблица матча                                       |
| `Esc`                 | закрыть закупку / освободить курсор                 |

После входа нажмите «ПРОДОЛЖИТЬ» в оверлее паузы, чтобы захватить курсор.

## Захват клавиш браузера

Пока курсор захвачен, игра блокирует типовые браузерные действия, которые страница имеет право отменять: `Ctrl+R`, `F5`, `Ctrl+F`, `Ctrl+S`, `Ctrl+P`, `Tab`, `Backspace`, `Ctrl+1…9`, `Alt+Left/Right` и подобные. `F11`, `F12` и сочетания DevTools не блокируются игровой логикой.

Зарезервированные браузером сочетания (`Ctrl+W`, `Ctrl+T`, `Ctrl+N`, `Ctrl+Tab`) обычная веб-страница отменить не может. Их можно перехватить только через полноэкранный режим и Keyboard Lock API, но этот режим отключён: в текущей реализации он иногда ломал захват мыши. Системные `Alt+F4`, `Ctrl+Alt+Del` и подобные веб-страница не перехватывает в любом случае.

`Esc` освобождает курсор и открывает паузу штатными средствами браузера.

## Кастомные прицелы

На стартовом экране нажмите «ИЗМЕНИТЬ ПРИЦЕЛ». Можно выбрать точку, крест, крест с точкой или полностью отключить прицел, а также настроить цвет, длину, толщину, зазор, размер точки и яркость. Выбранный вариант сохраняется в `sessionStorage` и применяется сразу.

Кнопка «СОХРАНИТЬ НА СЕРВЕРЕ» добавляет прицел в общий JSON-каталог `data/crosshairs.json`; он появляется у всех игроков. Рядом с сохранённым прицелом в списке есть кнопка удаления: она удаляет вариант из каталога, а классическую точку удалить нельзя. Каталог ограничен 100 вариантами, значения санитизируются и зажимаются в допустимые диапазоны. Сервер отдаёт `GET /api/crosshairs`, принимает `POST /api/crosshairs` и `DELETE /api/crosshairs/:id` (до 20 сохранений и удалений в минуту). Классическая точка доступна всегда, даже если файл каталога повреждён или отсутствует.

## Веб-админка

Админка поднимается отдельным HTTP-сервером на `ADMIN_PORT` (по умолчанию `3001`) и не зависит от терминала. Откройте `http://localhost:3001`: панель раз в 2 секунды обновляет состояние матча и позволяет управлять сервером из браузера.

По умолчанию админка слушает только `127.0.0.1`. Если открыть её по сети (`ADMIN_HOST=0.0.0.0`), сервер не запустится без `ADMIN_TOKEN`; токен должен быть не короче 8 символов. Тогда API потребует токен, а панель покажет форму входа. Токен хранится только в `sessionStorage` браузера. При доступе по сети используйте TLS или SSH-туннель: токен передаётся по обычному HTTP.

Возможности панели:

| Действие          | Что делает                                                 |
| ----------------- | ---------------------------------------------------------- |
| Состояние матча   | карта, фаза, раунд, счёт и список игроков с K/D и статусом |
| Смена карты       | `fy_sand` / `fy_wow` / `de_dust2`, сброс в лобби и релоад  |
| Кик игрока        | удаляет сессию и освобождает слот                          |
| Перезапуск матча  | сбрасывает счёт и запускает новый отсчёт                   |
| Завершение матча  | принудительно завершает текущий матч                       |
| Объявление        | показывает текст всем игрокам                              |
| Остановка сервера | корректно завершает игру и закрывает админку               |

HTTP API: `GET /api/state` возвращает состояние, `POST /api/command` принимает `{ "command": "...", "args": ["..."] }`. Команды те же, что были в терминале: `help`, `status`/`players`, `maps`, `map <id>`, `kick <ник|id>`, `restart`, `end`, `say <текст>`, `quit`.

Если задан `ADMIN_TOKEN`, передавайте его в заголовке `X-Admin-Token: <token>` или `Authorization: Bearer <token>`. Без токена API отвечает `401` с `{ "authRequired": true }`; после 10 неудачных попыток с одного адреса — `429`. Панель также отклоняет запросы с чужим `Host`/`Origin` в режиме без токена, чтобы исключить DNS-rebinding. В режиме с токеном `Host` не ограничивается, но `Origin` должен совпадать с `Host`; токен остаётся основным барьером, поэтому не открывайте панель по публичному DNS без TLS.

`kick` удаляет сессию игрока, поэтому клиент сможет зайти снова как новый участник. При `map` сервер рассылает `map_changed`, через 400 мс отключает старые сокеты, а клиенты перезагружают страницу с новой картой.

## Правила матча

### `arena` (`fy_sand`)

- Лимит: 16 фрагов или лучший счёт за 10 минут. Убийство завершает раунд.
- Стартовый набор: нож + Glock (alpha) или USP (bravo), броня 0.
- На карте: по два спавна Deagle, AK-47, M4A1, AWP, MP5 и M249, четыре HE-гранаты и два бронежилета.
- Подбор: оружие и гранаты со спавнов в пустой слот подбираются автоматически; `E` подбирает любое оружие с пола или заменяет его. `G` выбрасывает активное оружие или гранату, кроме ножа. Броня подбирается автоматически.
- Смерть: при смерти выпадают всё оружие и гранаты; победитель может подобрать их в окне `round_over`. Через 2.6 секунды победившая команда возвращается на базу с сохранённым оружием, патронами и бронёй, проигравшая — со стартовым набором; спавны восстанавливаются.
- Победа: первым набрать лимит раундов; при истечении времени побеждает лидер по раундам, при равенстве — ничья.

### `buy` (`fy_wow`, `de_dust2`)

- MR12 с бомбой C4: first to 13, смена сторон после 12 раундов, 12–12 = ничья, без OT. Стартовые стороны: alpha = T, bravo = CT (после смены сторон игроки спавнятся на базах своей новой стороны).
- Пленты: на `fy_wow` и `de_dust2` расположены две зоны закладки — **Плент A** и **Плент B** с тактическими укрытиями. Для CT в HUD не раскрывается, на каком именно пленте (A или B) установлена бомба. На `fy_sand` зон закладки нет.
- Бомба C4: в начале каждого раунда выдаётся живому T-игроку (после смены сторон в халфтайме — новому T). T может сбросить бомбу клавишей `G`; также она выпадает при смерти носителя. Подобрать упавшую бомбу (автоматически или по `E`) может только живой T.
- Установка и разминирование: зажатие `E` (`useHeld`) в зоне плента A или B устанавливает бомбу за **3 секунды** (только стоя на земле; во время установки/разминирования блокируются ходьба, прыжок и стрельба, но разрешён поворот камеры; отпускание `E` сбрасывает прогресс). Таймер до взрыва — **30 секунд**. Пока бомба установлена, таймер раунда (`1:25`) не завершает раунд, а убийство T не приносит мгновенную победу CT — CT обязан обезвредить бомбу. Разминирование зажатием `E` занимает **8 секунд** без кита и **4 секунды** с `Defuse Kit`.
- Тайминги: freeze 3 секунды, раунд 1:25 (до установки бомбы), закупка 20 секунд с начала live-раунда. Закупаться, переключать оружие и перезаряжаться можно уже в freeze-фазе.
- Стартовые деньги: `$800`, кап `$16 000`. Победа по фрагам/времени — `$3 250`, победа по взрыву или обезвреживанию C4 — `$3 500`. Бонус установщику бомбы — `+$500`, бонус сапёру за дефьюз — `+$300`. Лосс-бонус `$1 400/$1 900/$2 400/$2 900/$3 400`; победа сбрасывает тир. Награды за килл зависят от оружия, HE/граната/нож — отдельно.
- Закупка: только на спавне в бай-зоне, только живым и только в freeze + первые 20 секунд live. `B` открывает меню со всеми категориями. Вне бай-зоны снизу показывается уведомление, открытое меню закрывается. `G` в buy-режиме сбрасывает только бомбу C4 (оружие вручную не выбрасывается); подбирать дроп можно, включая `round_over`.
- Возврат: только последняя покупка текущего раунда, только неиспользованный предмет, полная цена. Убитым и после окончания времени закупки возврат недоступен.
- Kevlar `$650`, Kevlar+Helmet `$1 000` (апгрейд шлема при готовом кевларе — `$350`), Defuse Kit `$400` только CT. Шлем защищает голову; без шлема хедшот проходит мимо брони.
- Гранаты: максимум 4, flash — до 2, HE/smoke/molotov/incendiary — по 1. `4` циклически переключает тип, ЛКМ бросает. Гранаты нельзя выбрасывать.
- Выживший сохраняет оружие, патроны, броню, шлем, кит и гранаты. Умерший теряет всё, кроме ножа/стартового пистолета. В халфтайме деньги, лосс-бонус и лоадаут сбрасываются.
- Смена карты из веб-админки сбрасывает матч в лобби; клиенты перезагружаются и подключаются к новой карте и режиму.
- Выход соперника: техническая победа оставшегося игрока.

## Сетевая модель

- Сервер тикает с частотой 30 Гц и использует фиксированный шаг симуляции.
- Клиент отправляет только намерения: `forward`, `strafe`, `yaw`, `pitch`, `jump`, `crouch`, `walk`, `fire`, `scoped`, `reload`, `use`, `drop`, `switchTo`.
- Вместе с вводом клиент передаёт `aimTime` — серверное время отрисованного удалённого кадра. По нему сервер реветрит цели, поэтому попадания проверяются по той позиции, которую игрок реально видел.
- Сервер хранит последний ввод и игнорирует ввод старше 250 мс, чтобы отпущенная клавиша не «залипала». Нажатия полуавтоматического оружия дополнительно ставятся в очередь, поэтому быстрый клик между двумя тиками не теряется.
- Снапшоты содержат позиции, состояние игроков (включая `walking`), счёт, фазу и режим матча, `mapId`, стороны, деньги, броню/шлем/кит, гранаты, таймеры закупки и раунда, доступное оружие и летящие гранаты.
- Удалённые игроки интерполируются с задержкой 70–180 мс (адаптивный jitter buffer), локальный — ~30 мс. HUD показывает ping, jitter и оценку потерь снапшотов.
- Для выстрела сервер выбирает историческую позицию цели в пределах 300 мс и проверяет попадание по составным хитбоксам: сфера головы и вертикальные цилиндры корпуса/ног. Событие `hit` содержит `sourcePosition` для индикатора направления урона и whiz-звука.
- В конце каждого раунда, включая финальный, сервер отправляет `round_summary` с раундовой и накопительной статистикой обоих игроков; клиент обновляет таблицу по `Tab`. Покупки и возвраты подтверждаются событием `buy_result`.
- При разрыве соединения матч переходит в `paused`; после возвращения обоих игроков запускается короткий отсчёт и матч продолжается.
- Если игрок не вернулся за 60 секунд, оставшийся получает победу по `abandon`.

## Протокол

- `PROTOCOL_VERSION = 13`; при несовпадении версии Socket.IO отклоняет подключение.
- Клиент → сервер: `join`, `input`, `buy`, `refund`, `rematch`, `leave`, `ping`.
- Сервер → клиент: `serverHello`, `pong`, `lobby`, `countdown`, `snapshot`, `hit`, `shot`, `kill`, `pickup`, `armor_pickup`, `grenade_thrown`, `explosion`, `bomb_event`, `buy_result`, `score_update`, `round_end`, `round_summary`, `map_changed`, `announce`, `server_error`.
- `serverHello` содержит `mapId`, `mapName` и `mode`; `lobby` и `snapshot` — `mapId` и режим. `snapshot` также содержит `armorPickups`, `grenades`, `buyEndsAt`, `roundEndsAt`, `roundsToWin`, `sideSwapAfterRound`, стороны игроков, деньги, шлем/кит, гранаты и `lastPurchaseId`. `hit` содержит `sourcePosition`, а `round_summary` — `round`, `winnerId`, `winnerName` и массив `players` со статистикой.
- Валидация входящих payload через Zod; ограничение частоты `input`, `join`, `buy`/`refund`, `rematch`, `ping` и сохранения прицелов на сокет/сервер.
- Имена санитизируются: control-символы удаляются, пробелы схлопываются, длина — до 16 code points.
- `GET /api/crosshairs` возвращает классическую точку и сохранённые прицелы; `POST /api/crosshairs` сохраняет новый прицел, `DELETE /api/crosshairs/:id` удаляет сохранённый (классическую точку удалить нельзя); не более 100 прицелов, до 20 сохранений и удалений в минуту.

## Ограничения

- Нет базы данных, аккаунтов, статистики между перезапусками и matchmaking.
- Один серверный процесс = один матч 1v1.
- Нет мобильного управления и геймпада.
- Для pointer lock и звука нужен пользовательский жест (клик по кнопке или канвасу).
- Для игры по локальной сети откройте адрес из логов сервера (`Network: http://...`), а не только `localhost`.
